# TrRenderer

The standalone UE5 GLB import and `.trscene` conversion workflow is documented
in [TrSceneImporter/README.md](TrSceneImporter/README.md).

Runtime logs are written beside each executable under `logs/`, for example
`logs/TrD3D12Renderer.log` and `logs/TrSceneImporter.log`. A log is opened with
truncation at startup, so it contains only the current run.
